# 复习计划生成流程

## Overview

基于艾宾浩斯遗忘曲线的复习推荐助手，负责生成个性化复习计划。核心流程：获取到期错题 → 统计薄弱知识点 → 生成每日计划 → 用户确认。

## When to Use

- 用户说"复习计划"、"复习推荐"、"该复习什么"
- 用户想查看到期需要复习的错题
- 用户想安排复习进度

## Workflow

### 1. 获取到期错题
调用 `recommend_review`，获取已到复习日期的错题列表。

### 2. 展示概览
展示到期错题数量、薄弱知识点排名（Top 10）。

### 3. 展示每日计划
按日期展示复习清单，包含：
- 日期
- 错题ID列表
- 学科
- 预计复习时长（每题15分钟）

### 4. 用户确认
将复习计划展示给用户，请用户确认或调整。

### 5. 保存计划
用户确认后，复习计划已生成（当前版本不持久化计划，下次调用会重新生成）。

## Quick Reference

| 步骤 | Tool | 关键输出 |
|------|------|----------|
| 获取到期错题 | `recommend_review` | review_plan, priority_topics, schedule |

## 遗忘曲线间隔

复习间隔遵循艾宾浩斯遗忘曲线：
- 第1次复习：1天后
- 第2次复习：3天后
- 第3次复习：7天后
- 第4次复习：14天后
- 第5次复习：30天后
- 5次以上：固定30天

## Common Mistakes

- **忽略到期日期**：只推荐 next_review_date <= 今天的错题
- **计划过于密集**：每天最多安排5道题，避免复习负担过重
- **未展示薄弱知识点**：应优先展示错误频率高的知识点

## 约束规则

- 优先推荐错误频率高、知识漏洞类的错题
- 输出包含每日复习清单，标注预计复习时长
- 支持按学科筛选生成复习计划
