# 复习计划生成流程

## Overview

基于 FSRS v6 到期推荐助手的复习推荐工具，负责生成个性化复习计划。核心流程：获取到期错题 → 统计薄弱知识点 → 生成每日计划 → 用户确认。每次复习按 FSRS v6 调度动态推算下次复习日期（按记忆难度/稳定性 + 4 档评分调整），非固定间隔查表。

## When to Use

- 用户说"复习计划"、"复习推荐"、"该复习什么"
- 用户想查看到期需要复习的错题
- 用户想安排复习进度

## Workflow

### 1. 获取到期错题
调用 `recommend_review`，获取已到复习日期的错题列表。

### 2. 展示概览
展示到期错题数量、薄弱知识点排名（Top 10）。

### 3. 展示每日计划
按日期展示复习清单，包含：
- 日期
- 错题ID列表
- 学科
- 预计复习时长（每题15分钟）

### 4. 用户确认
将复习计划展示给用户，请用户确认或调整。

### 5. 保存计划
用户确认后，复习计划已生成（当前版本不持久化计划，下次调用会重新生成）。

## FSRS v6 到期排程

复习排程由 FSRS v6 间隔重复调度驱动，每次复习按记忆难度(difficulty)、稳定性(stability)动态计算下一到期日期（4 档评分调整间隔），并随刷题数据积累支持个性化参数优化。到期推荐规则：

- 只推荐 `next_review_date <= 今天` 的错题
- 每天最多 5 道题，避免复习负担过重
- 优先推荐错误频率高、知识漏洞类的错题

## Common Mistakes

- **忽略到期日期**：只推荐 next_review_date <= 今天的错题
- **计划过于密集**：每天最多安排5道题，避免复习负担过重
- **未展示薄弱知识点**：应优先展示错误频率高的知识点

## 约束规则

- 优先推荐错误频率高、知识漏洞类的错题
- 输出包含每日复习清单，标注预计复习时长
- 支持按学科筛选生成复习计划
