# 错题采集流程

## Overview

K12错题采集助手，负责将纸质/图片错题转化为结构化数据并保存。核心流程：宿主LLM多模态看图解析 → AI结构化解析 → 智能分类 → 用户确认 → 保存记录。图片解析由宿主LLM的多模态能力直接完成，不依赖任何外部识别服务。

## When to Use

- 用户说"录入错题"、"拍照录题"、"添加错题"、"上传错题"
- 用户提供错题图片路径或要求直接输入题目文本
- 用户需要将错题保存到本地数据库

## Workflow

### 1. 获取图片
要求用户提供错题图片路径，或允许直接输入题目文本。

### 2. 多模态图片解析
直接使用宿主LLM的多模态能力**读取图片**，理解图片中的题目内容。注意：
- 图片仅存本地 `data/images/`，禁止上传任何外部服务
- 若图片路径无效、无法读取或看不清，提示用户重新提供图片或直接输入题目文本

### 3. AI结构化解析
基于图片解析出的题目内容（或用户直接输入的文本），按以下JSON结构提取题目数据：
- 学科、年级段
- 知识点标签
- 难度、题型
- 题目内容（`question_content`）、选项（`options`）、正确答案

输出JSON格式（不要输出其他内容）：
```
{
    "subject": "学科（语文/数学/英语/物理/化学/生物/政治/历史/地理）",
    "grade_level": "年级段（小学/初一/初二/初三/高一/高二/高三）",
    "knowledge_points": ["知识点1", "知识点2"],
    "difficulty": "难度（基础/中等/困难）",
    "question_type": "题型（选择题/填空题/计算题/证明题/应用题/其他）",
    "question_content": "题目内容（修正模糊处后的完整题目）",
    "options": ["选项A", "选项B", "选项C", "选项D"],
    "correct_answer": "正确答案（如果能推断出）"
}
```
注意事项：
1. 修正图片中肉眼可见的模糊或错误处
2. 数学公式用LaTeX格式表示
3. 如果无法确定某个字段，填null
4. knowledge_points必须从该学科的标准知识点中选择

### 4. 展示确认
将解析结果以结构化格式展示给用户，请用户确认或修改。

### 5. 智能分类
调用 `classify_question` Tool，用 `classify_prompt` 调用AI分类，确定：
- 错误类型（知识漏洞/粗心失误/方法错误/审题失误）
- 错误细分类别
- 相关知识点

### 6. 展示分类
将分类结果展示给用户，请用户确认或修改。

### 7. 保存记录
调用 `save_wrong_question`，生成 question_id（格式：wq_YYYYMMDD_NNN）。

## Quick Reference

| 步骤 | Tool | 降级方案 |
|------|------|----------|
| 多模态看图解析 | 宿主LLM直接读取图片 | 手动输入题目文本 |
| 结构化解析 | 宿主LLM按内联JSON结构提取 | 标记待确认 |
| 智能分类 | `classify_question` | 标记待确认 |
| 保存记录 | `save_wrong_question` | - |

## Common Mistakes

- **图片无法解析直接报错**：应提示用户手动输入或更换图片，而非终止流程
- **将图片上传外部服务**：图片仅存本地 `data/images/`，禁止外传
- **跳过用户确认**：分类和解析结果必须经用户确认后才保存
- **知识点自由生成**：知识点必须来自学科知识图谱，不可自由生成
- **question_id格式错误**：必须使用 wq_YYYYMMDD_NNN 格式

## 约束规则

- 学科必须从K12标准列表选择：语文/数学/英语/物理/化学/生物/政治/历史/地理
- 错误类型限定4类：知识漏洞/粗心失误/方法错误/审题失误
- 知识点标签必须来自学科知识图谱
- 分类结果必须经用户确认后才保存
